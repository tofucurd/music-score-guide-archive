# 贝多芬第九交响曲

最终版本为 production04：Klaus Tennstedt 指挥伦敦爱乐乐团与合唱团，1992年10月8日现场录音。成片71分51秒、258660帧、3840×2160/60fps；NVENC p7/hq、HEVC 10bit 4:4:4、CQ16、maxrate25M/bufsize50M，原录音PCM16bit/44.1kHz无损封装，含四乐章样本章节。

## 保存内容

四乐章的正式 score.json、原生score.svg、geometry、最终alignment、音频元数据、中文声部名、材料与两层曲式导航；修订MusicXML；最终人声timeline/cohort/layout及面板策略；精选材料染色；谱号/调号与移调乐器标签；实际生产renderer及其直接依赖。大文件按 `inventory.json` 以gzip保存。

唱词使用采用钱译之前的已复核版本（原表SHA `850e078955bc0ccc3ba4411d5a72825b7abf31dae4a8167131a67f1ee59084e2`），包含全部67个分句、547处出现。保留稳定声部标签、下一句预告、0.30秒位置/字号/颜色同步过渡、长音条及至少15秒完全隐去间隔的整栏收起规则。

原声是主时钟。第一乐章只沿用既定的开头5秒裁切；四章最终时间映射、演奏反复路线、音符与歌词时段不重新拟合。`delivery-record.json` 保存已交付文件的指纹与章节，不附带成片。

## 使用

按仓库根README调用 `archive.py restore/prepare-audio/render/covers beethoven9`。`sources.json` 列出四个外置FLAC和参考PDF；只分享音频标签与规格，不分享音频。完整的冻结画面不依赖重新读取PDF或执行OpenScore导入。

封面采用第四乐章第121—132个源小节、巴松/大提琴/低音提琴，16:9与4:3分别排版，指挥中文姓名为“滕施泰特”。实际使用的纸色、思源宋体和细字重IX均由冻结代码与配置保存。

路径匿名化改变了部分JSON文件的字节哈希，因此清单保存原哈希与公开文件哈希；唱词/材料层的校验绑定同步到公开快照。仅供历史审查而不参与逐帧计算的论文、旧版赋值文件和原始MXL不加入运行绑定；正式谱面、几何、时钟与当前材料映射仍互相绑定。这些处理不重算音乐数值或排版。
