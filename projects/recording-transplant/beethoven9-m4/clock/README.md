# 第四乐章第 15 版的时间映射

**15 全乐章多尺度声学对齐＋谱面音序复核＋乐句脉动约束（Rubber Band R3）＋打击乐分声部调整**

在第四乐章项目目录执行以下命令，可从两条初始时钟和原工程保留的测量读数重新计算定稿的时间映射。这一步仅处理数值。音频重建可直接读取项目已附的定稿参数。

```sh
python -m pip install numpy scipy
python clock/fit.py --out build/clock
```

| 输出 | 单位及方向 | 定稿 SHA-256 |
| --- | --- | --- |
| `command.csv` | 30,177 对时间坐标，单位为秒。左列是滕斯泰特的时间，右列是目标演绎时间。含首尾坐标。 | `676fd741e2cab39b2218eafdd08d53060806dc83f25c68a975704b6293c37a6f` |
| `engine-keyframes.txt` | Rubber Band R3 使用的 24,344 对内部采样位置，采样率为 44,100 Hz。全曲起点与终点由播放时长指定。 | `89e09d4a6c0cfb901c4721930eedb95af039a3581253d9d1558265c33d596154` |

在 NumPy 1.24.3、SciPy 1.11.1 下重算，两份输出的 SHA-256 均与发布所用文件相同。

## 算法与输入

1. 以乐谱四分音符为坐标，寻找相同声部在等谱面时距上的连续三次起奏。先按拍位、节拍、跨度和谱面标记分组，再从邻近小节的同类起奏估计时值关系。全乐章共有 9,232 个可比较的观测。
2. 在整条时间映射上联立求解。乐句端点、休止与明确的速度标记约束局部位移。已识别乐器或音高的起奏按各自的不确定度加权。两组平滑权重分别产生偏向整句和偏向局部起奏的解。
3. 利用连续钹击的原演读数和一次中间渲染的钹击回读，估计对应位置的相位偏差。局部起奏证据得到相邻音支持时，再融入整句解。若一整串已识别音的旧时钟本已吻合，也允许保留该段旧时钟。
4. 将校正后的时刻量化到采样，在保留既有引擎键的基础上对残差分段线性插值。把误差超过七个采样的位置递归加入引擎键表。最终渲染由滕斯泰特原演一次变速完成。

| 定稿输入 | 内容 |
| --- | --- |
| `priors.npz` | 前一轮已接受的初始时钟、正则化时钟与对应引擎采样键，均为数值数组。 |
| `score-context.json` | 943 小节的起止坐标、速度及延长记号分类、分段位置与各声部起奏的谱位。 |
| `donor-onsets.csv` | 滕斯泰特的 3,986 个起奏谱位及其时间和权重。含 29 个由独立检测取得一致结果的钹击。 |
| `identified-attacks.csv` | 483 对两份录音中已识别的起奏时间，附测量不确定度、证据类别和留出标记。 |
| `coda-returns.csv` | 尾声在富特文格勒原演和初步渲染中有观测支持的 34 项钹击读数。 |

更换任一录音时，需要重新测定该录音的起奏、与乐谱的关系及初始时钟。这些步骤在此版本中以定稿输入表为重现起点。打击乐的分声部力度调整在音频构建阶段完成。
